
# School Science Fair Project Evaluator

A beginner-friendly C++ console project to manage school science fair project records.

## Features
- Add new science projects
- View all saved projects
- Display total number of projects
- Validate project details
- Prevent duplicate project IDs
- Store up to 5 projects using an array

## C++ Concepts Used
- Classes and Objects
- Static Members
- Inline Functions
- Friend Functions
- Array of Objects
- Pointers
- `this` Pointer
- `std::string`

## Technologies Used
- C++
- Visual Studio Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program:

   g++ main.cpp -o main

4. Run the program:

   .\main.exe

## Storage
Project records are stored in memory and are lost when the program exits.
